# 常见问题

## TradingHero 中没有显示 MT4 或 MT5 交易入口

检查 `config.json` 是否位于 `TradingHero.exe` 同级目录，并确认：

- 根节点是 JSON 数组。
- `feat` 只能填写 `MT4` 或 `MT5`。
- Token 长度不少于 24 个字符。
- 修改配置后已经完全退出并重新启动 TradingHero。

## EA 日志提示 Token 缺失

正常情况下，TradingHero 会在以下位置写入 `bridge.conf`：

- MT4：`MQL4\Files\TradingHero\bridge.conf`
- MT5：`MQL5\Files\TradingHero\bridge.conf`

检查 TradingHero 是否能够找到正确的数据目录。也可以在加载 EA 时临时把与 `config.json` 相同的 Token 填入 `BridgeToken`，但不要截图、上传或提交该值。

## 出现 WebRequest 5200 错误

常见原因是没有允许本地网关地址，或地址与平台不匹配：

- MT4：`http://127.0.0.1`
- MT5：`http://127.0.0.1:81`

修改后重新加载 EA。不要将两个地址混用。

## TradingHero 一直显示等待 EA 连接

依次检查：

1. TradingHero 和对应 MetaTrader 是否都在运行。
2. EA 是否已经加载到一个保持打开的图表。
3. EA 日志中是否有 Token、WebRequest 或连接错误。
4. `config.json` 与 `bridge.conf` 中的 Token 是否一致。
5. 本机端口 80（MT4）或 81（MT5）是否被其他程序占用。

## 能查看数据但不能下单

需要同时满足：

- EA 参数 `AllowLiveTrading=true`。
- MT4 已开启“自动交易”，或 MT5 已开启“算法交易”。
- EA 属性中允许实时/算法交易。
- 当前交易账户已连接，并且经纪商允许该品种交易。

## 品种列表为空

确认 MetaTrader 已登录交易服务器，并检查市场报价窗口中是否存在可交易品种。刷新导航器或重新加载 EA 后等待一个快照周期。

## 已编译 EA 无法加载

MetaTrader Build 版本或经纪商定制终端可能造成兼容问题。使用该终端自带的 MetaEditor 打开对应源码并重新编译：

- MT4：`TradingHeroBridge.mq4`
- MT5：`TradingHeroBridge.mq5`

## 如何更换 Token

1. 修改 `TradingHero.exe` 同级目录中的 `config.json`。
2. 完全退出并重新启动 TradingHero。
3. TradingHero 会重新写入 `bridge.conf`。
4. 重新加载 EA，确认日志不再出现认证错误。

不要在 GitHub Issue、截图或日志中粘贴真实 Token。
